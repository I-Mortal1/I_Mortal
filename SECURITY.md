# I_Mortal security notice

This repository contains project documentation only. It distributes no wallet application, signing service, executable, deployment configuration or user-fund functionality.

The implementation remains in development. Published test counts describe their stated software scopes, not independent certification or a guarantee of security. Do not use this overview as evidence that a live wallet or trading system is safe for funds.

## Reporting concerns

Use GitHub's private vulnerability-reporting option for this repository when available. If that option is unavailable, request a private reporting route through the [maintainer's public profile](https://github.com/I-Mortal1) before sharing sensitive details.

Do not post passwords, API credentials, wallet private keys, recovery phrases, identity documents, account information, exploit payloads containing secrets or internal deployment details in public issues or discussions. A documentation report should use a redacted description and the affected public page.

The project does not need a user's secret material to receive a report. No production bug-bounty program, response-time commitment or security certification is announced by this document.
